# PARAMETROS

Esta pasta pode conter objetos e códigos que servem para armazenar parâmetros utilizados em chamadas API ou criar tabelas seed no DW.

`atualizar_deputados.py`
- Serve para obter ID de deputados e detalhes da legislatura

`dbt_seed_maker`
- Serve para obter tabelas estáticas e persistir no seeds do dbt DW.
